## 事实核对（避免被打脸）

- 54 个模块、2.1 万行 Python、128 个公开名字 —— 实测统计
- 16 个示例页面 —— `examples/basics/window.py` 的 `pages`（16）+ `hidden_pages`（2）
- 支持 Python 3.8–3.14 —— README 声明
- 依赖 Pillow + conf_base —— `pyproject.toml`
- 毛玻璃依赖 Windows 11 DWM，其它平台退化 —— README 已注明，正文也写了
- 「只有一套深色配色」是当前设计取舍，正文在对比表里如实写了

## 如果读者问「为什么不用 ttkbootstrap」

正文的对比表已经回答了。补充口径：ttkbootstrap 是 ttk 样式表 + 主题，改的是「系统控件的皮」；ctk-kit 是自绘控件 + 令牌，改的是「控件本身」。两者定位不同，不是替代关系。
